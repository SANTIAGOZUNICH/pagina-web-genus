GENUS WEB ASSETS

Paquete visual inicial para el rediseño de Laboratorio Genus.

Carpetas:
01_brand: imágenes generales / hero.
02_categorias: Capilares, Styling, Faciales, Sérums, Limpieza, Corporales, Brumas & Sprays y Otro producto.
03_productos: renders agrupados por tipo de producto.
04_composiciones: conjuntos de varios envases para líneas o desarrollos especiales.
05_texturas: fondos, líquidos y pedestales.
06_ui: recursos visuales para el configurador (Creamy, pasos, marca, colores, logo).
07_creamy: referencia original de Creamy aportada por el usuario.

Nota: estos recursos son un kit conceptual inicial extraído del tablero visual generado. Para producción final conviene generar cada render maestro por separado y, si se implementa rotación 3D real, crear modelos GLB/GLTF específicos.
