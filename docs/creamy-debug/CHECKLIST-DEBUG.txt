BLOQUE 3 — VERIFICACIÓN EN CONSOLA DEL NAVEGADOR
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Abrir el sitio → F12 → Console + Network (filtrar por "chat")

[ ] 3.1 Al abrir Creamy, verificar en Console:
    Debe aparecer: [Creamy] POST → /api/creamy/chat
    NO debe aparecer: [Creamy] usando mock
    NO debe aparecer: useMock: true

[ ] 3.2 Al enviar un mensaje, verificar en Network tab:
    → Debe existir un request POST a /api/creamy/chat
    → Status debe ser 200
    → Response debe tener el campo "reply" (no vacío)
    → Response debe tener el campo "meta" con "model": "gpt-4o-mini"

[ ] 3.3 Verificar el payload del request (Network → request → Payload):
    → "message": [texto del usuario]
    → "conversation_history": [array]
    → "session_id": [string]

[ ] 3.4 Verificar la respuesta (Network → request → Response):
    → "reply": [texto generado por IA, no un mock hardcodeado]
    → "meta.model": "gpt-4o-mini" (confirma que pasó por OpenAI)
    → "meta.knowledge_loaded": true (confirma que el JSON se leyó)
    → "meta.used_fallback": false (confirma que NO usó fallback)

BLOQUE 4 — VERIFICACIÓN EN LOGS DE VERCEL
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Vercel Dashboard → tu proyecto → Logs (o Deployments → Functions)

Cada request a /api/creamy/chat debe generar estos logs en orden:

[ ] 4.1  [CREAMY:REQUEST_START] { requestId, method: "POST" }
[ ] 4.2  [CREAMY:API_KEY] { present: true, prefix: "sk-proj-..." }
[ ] 4.3  [CREAMY:PROMPT] { loaded: true, chars: [número > 1000] }
[ ] 4.4  [CREAMY:KNOWLEDGE] { loaded: true, products: [número > 0] }
[ ] 4.5  [CREAMY:SYSTEM_PROMPT] { knowledge_injected: true }
[ ] 4.6  [CREAMY:OPENAI_REQUEST] { model: "gpt-4o-mini", ... }
[ ] 4.7  [CREAMY:OPENAI_RESPONSE] { success: true, elapsed_ms: [número] }
[ ] 4.8  [CREAMY:RESPONSE_PROCESSED] { has_actions: ..., used_fallback: false }

Señales de problema:
→ [CREAMY:ERROR:PROMPT_LOAD] = system-prompt.txt no se encuentra
→ [CREAMY:ERROR:KNOWLEDGE_LOAD] = creamy-knowledge.json no se encuentra
→ [CREAMY:ERROR:OPENAI_CALL] = error de API (clave inválida, cuota, etc.)
→ [CREAMY:API_KEY] { present: false } = CRÍTICO, redeploy con la clave
